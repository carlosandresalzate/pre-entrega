# Maquetado HTML

El maquetado HTML consiste en estructurar y organizar el contenido de una página web usando etiquetas HTML para crear un esqueleto funcional y semántico que luego puede ser estilizado con CSS.

## Qué es el maquetado HTML

El maquetado web es el proceso de crear la estructura de una página mediante código HTML, definiendo cómo se disponen los elementos como textos, imágenes, enlaces, formularios y secciones de contenido.
Esta estructura es fundamental para garantizar que la página sea accesible, funcional y coherente en distintos dispositivos y navegadores.
Además, un buen maquetado mejora la experiencia del usuario y facilita la navegación y comprensión del contenido.

## Elementos y etiquetas clave

HTML5 ofrece etiquetas semánticas que ayudan a organizar el contenido de manera clara:

- `<header>`: Encabezado de la página o sección
- `<nav>`: Contenedor de enlaces de navegación
- `<section>`: Sección del documento
- `<article>`: Contenido independiente, como un artículo
- `<aside>`: Contenido complementario, como barras laterales
- `<footer>`: Pie de página o de sección
- `<details>` y `<summary>`: Información adicional desplegable
  Para contenido básico se utilizan etiquetas como `<p>` para párrafos, `<h1>` a `<h6>` para encabezados, `<ul>` y `<ol>` para listas, `<a>` para enlaces e `<img>` para imágenes.

## Buenas prácticas

- Mantener una estructura semántica clara para mejorar accesibilidad y SEO
- Evitar usar `<table>` para maquetar la página; su uso debe limitarse a datos tabulados
- Planificar la disposición de los elementos antes de codificar, considerando la usabilidad y experiencia del usuario
- Combinar HTML con CSS para separar estructura y estilo, evitando colocar todos los estilos directamente en los atributos de las etiquetas

## Tipos de maquetación

- **Fija**: Diseño predecible que mantiene la misma apariencia en distintos dispositivos, aunque menos adaptable a móviles
- **Flotante o basada en CSS**: Permite crear plantillas multi-columna y diseños más flexibles, aunque requiere controlar el flujo de los elementos
- **Responsive**: Adaptable a diferentes tamaños de pantalla usando CSS y media queries, ideal para dispositivos móviles

## Proceso básico de maquetado

1. Crear la estructura básica con `<html>`, `<head>` y `<body>`
2. Definir la barra de navegación con `<nav>` y listas de enlaces
3. Organizar el contenido en secciones y artículos usando `<section>` y `<article>`
4. Añadir elementos visuales como imágenes y formularios
5. Aplicar estilos con CSS para mejorar la estética y la experiencia del usuario

En resumen, dominar el maquetado HTML permite construir páginas web bien organizadas, semánticamente correctas y listas para ser estilizadas con CSS, asegurando funcionalidad, accesibilidad y una experiencia de usuario óptima.
